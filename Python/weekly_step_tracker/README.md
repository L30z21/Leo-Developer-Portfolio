# Weekly Step Tracker

## About
A beginner-friendly Python project that tracks daily steps over one week and calculates useful statistics.

## Features
- Calculates total steps for the week.
- Calculates average daily steps.
- Counts how many days the daily step goal was reached.

## Technologies
- Python

## Sample Data
The program uses seven daily step counts and a daily goal of 10,000 steps.

## Example Output
```text
Total steps this week: 63500
Average daily steps: 9071.43
Days goals reached: 2
```

## How to Run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this project folder.
3. Run:

```bash
python step_tracker.py
```
