# Python Guessing Game

## About the Project
This is a simple number guessing game built with Python. The player tries to guess a secret number within a limited number of attempts.

## How It Works
- The game stores a secret number.
- The player has three attempts to guess it.
- The program tells the player when they guess correctly.
- If all attempts are used without a correct guess, the program displays a losing message.

## Concepts Practiced
- Variables
- User input with `input()`
- Type conversion with `int()`
- `while` loops
- `if` statements
- `break` and `while...else`

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

   ```bash
   python guessing_game.py
   ```
